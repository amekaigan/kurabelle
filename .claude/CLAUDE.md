## このサイト

- ドメイン kurabelle.com はお名前.comで取得（2026年10月）、ネームサーバーを Cloudflare（joselyn / achiel）に切り替え済み。kurabelle.com・www.kurabelle.com とも Pages のカスタムドメインで有効。
- 反映の確認：`https://kurabelle.com/version.txt` にビルドした日時とコミットが出る。GitHub のコミットに「Cloudflare Pages」のチェックが付けばビルドが動いている。
- 自動の反映が止まったとき（2026年10月16日に一度あった）：GitHub の Settings → Applications →「Cloudflare Workers and Pages」→ Configure で、kurabelle を外して保存し、もう一度追加して保存すると直った。Cloudflare の「切断」は押さない。
- 商品データは `data/products.json` の1ファイル。ページはすべて `src/gen.js` が作る（商品・成分・ブランド・目的別・カテゴリ）。
- 診断つきの比較ツールは `app/index.html`（1ファイル）。ビルド時に gen.js が、サイトと同じヘッダー・フッター（`<!--KB:HEAD-->` `<!--KB:FOOT-->` の位置）を差し込み、products.json と一緒に `dist/app/` に置く。ヘッダー・フッター・方眼の背景は `src/chrome.css`（サイトと比較ツールで共通）。

## クラベルだけのルール
- **成分表は一字一句そのまま写す。** 同じページを2回取得し（番号つきの一覧とJSON配列）、プログラムで突き合わせて一致したものだけ入れる。全角英数は半角にそろえる。出典はメーカー公式か販売店のページだけ。成分解析サイトは使わない。出典URLと確認日を必ず残す。
- **効果をうたわない（薬機法）。** 点数は「成分表に何が入っているかを決まったルールで数えたもの」で、効果・使い心地ではないと書く。化粧品に「育毛」「フケを防ぐ」などの効能を書かない。医薬部外品の効能は、パッケージや公式ページの表示どおりの言葉だけ。
- **マイナスの印象を与える書き方をしない。** 値段が高い・安いの評価は書かない。「入っている／入っていない」は良い悪いではないと添える。
- 成分の安全性や海外の規制に触れるときは、EUの化粧品規則・米国FDAなどの一次資料で確かめ、条文や日付を添える。「危険」「有害」など、規制の中身より強い言葉は使わない。
- 運営者の感想（`reviews`）は、ユーザー本人が書いた内容だけ。前の商品の感想を後継品に載せるときは、その旨を必ず書く。
- **楽天ウェブサービスの規約**：取得した商品画像・商品情報をサイト側に保存しない（ページを開いた人のブラウザで `assets/rk.js` が都度読み込む）。楽天の情報を使う商品に、楽天以外のアフィリエイトを付けない。クレジット表示をフッターに出す。楽天への問い合わせは `functions/api/rk.js`（Cloudflare Pages Functions、`/api/rk`）が取り次ぎ、アクセスキーをページに出さない。鍵は Cloudflare の環境変数 `RAKUTEN_APP_ID`（テキスト）と `RAKUTEN_ACCESS_KEY`（シークレット）に、ユーザーが自分で入れる（チャットで受け取らない）。アフィリエイトIDは `src/build.js` と `functions/api/rk.js`。
- **商品を追加する手順（2026年10月17日〜）**：
  1. 調べる前に `python3 tools/check.py find <JANか商品名>` で、公開中・待機中・見送り済みかを確かめる（重複と、止まった商品の調べ直しを防ぐ）。
  2. 全成分は別々の2サイト（メーカー公式を優先）から取る。2サイト目がなければ同じページを番号つき一覧とJSON配列で2回取る。2回目も1回目を流用せず、取得結果をそのまま `tools/cands/*.py` に貼る。
  3. `python3 tools/check.py` で照合（一字一句・JANのチェックデジット・有効成分・重複・先頭の水）。`--write` で一致したものを登録、止まったものは `data/skipped.json` に理由つきで記録される。
  4. 新しいカテゴリの商品は `data/pending.json` に入り、そのカテゴリが10件たまったら自動で公開側（products.json）へ移る。
  5. 香り違いだけで成分が同じ商品は、重複ページになるので登録しない。
  6. 全成分が載っている出典の目安：花王 製品カタログ、ツルハ、マツキヨココカラ、セイムス（クリエイトSDは成分欄がない商品が多い）。
  7. 週の目標件数はユーザーと相談して決める（2026年10月17日時点で見直し中）。
- 中身の薄いページを作らない：成分ページは商品2件以上かつ辞書に説明がある成分だけ、ブランドページは商品3件以上。
