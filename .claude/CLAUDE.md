# クラベル（kurabelle.com）作業ルール

Claude Codeが起動時に自動で読むファイル。`.claude/` に置くのは、ビルド結果（`dist/`）に入らず公開されないようにするため。

## このサイト
- シャンプー・保湿クリームなどの**成分表を、決まったルールで読み解いて比べる**サイト。サイト名は「クラベル」（ロゴの横に小さく kurabelle。検索結果のタイトルは「クラベル｜成分でくらべるシャンプー・スキンケア」）、ドメインは kurabelle.com。
- 本番は Cloudflare Pages（アカウント Ishimonzukan、プロジェクト kurabelle）が `npm run build`（`src/build.js`）を実行し、`dist/` を公開する。`dist/` はリポジトリに入れない。GitHub は amekaigan/kurabelle（非公開）。
- ドメイン kurabelle.com はお名前.comで取得（2026年10月）、ネームサーバーを Cloudflare（joselyn / achiel）に切り替え済み。kurabelle.com・www.kurabelle.com とも Pages のカスタムドメインで有効。
- 反映の確認：`https://kurabelle.com/version.txt` にビルドした日時とコミットが出る。
- 商品データは `data/products.json` の1ファイル。ページはすべて `src/gen.js` が作る（商品・成分・ブランド・目的別・カテゴリ）。
- 診断つきの比較ツールは `app/index.html`（1ファイル）。ビルド時に gen.js が、サイトと同じヘッダー・フッター（`<!--KB:HEAD-->` `<!--KB:FOOT-->` の位置）を差し込み、products.json と一緒に `dist/app/` に置く。ヘッダー・フッター・方眼の背景は `src/chrome.css`（サイトと比較ツールで共通）。

## 話し方
- 返事は日本語。専門用語は言い換える：main→本番、ブランチ→作業用のコピー、PR→本番への反映の申請、マージ→本番に反映、push／コミット→作業用のコピーに保存、Routine→定期実行。
- ユーザーが自分で直す箇所を示すときは「検索」「置き換え」の形で書く。

## 裁量のルール（A／B／C）
2026年10月15日、ユーザーと決めた全サイト共通のルール。**このファイルの他の箇所とぶつかるときは、この節を優先する。**

| 段階 | 対象 | 進め方 |
|---|---|---|
| **A 聞かずに本番へ・あとで報告** | 誤字・脱字、リンク切れ、明らかな不具合の修正、裏側の仕組み（生成スクリプト・サイトマップなど）、作業メモの更新、**成分表を一字一句確認した商品の追加** | 本番に反映してから一言で報告する |
| **B まとめて確認** | 見た目の変更、新しい機能、**点数のルールの変更**、商品の説明文・香りの文の追加、アフィリエイトリンクの追加・差し替え | 作業用のコピーに貯めて、1日1回まとめて聞く。OKのものだけ本番に反映する |
| **C 必ず先に相談** | ファイル・ページの削除、公開URLの変更、料金・課金、規約・プライバシーポリシー、**成分の安全性・海外の規制についての記述を新しく載せること** | 作業に入る前に相談する |

- 迷ったら一つ上の段階として扱う。作業の前に本番の最新を取り込む。1回の保存は1つの目的に絞る。

## クラベルだけのルール
- **成分表は一字一句そのまま写す。** 同じページを2回取得し（番号つきの一覧とJSON配列）、プログラムで突き合わせて一致したものだけ入れる。全角英数は半角にそろえる。出典はメーカー公式か販売店のページだけ。成分解析サイトは使わない。出典URLと確認日を必ず残す。
- **効果をうたわない（薬機法）。** 点数は「成分表に何が入っているかを決まったルールで数えたもの」で、効果・使い心地ではないと書く。化粧品に「育毛」「フケを防ぐ」などの効能を書かない。医薬部外品の効能は、パッケージや公式ページの表示どおりの言葉だけ。
- **マイナスの印象を与える書き方をしない。** 値段が高い・安いの評価は書かない。「入っている／入っていない」は良い悪いではないと添える。
- 成分の安全性や海外の規制に触れるときは、EUの化粧品規則・米国FDAなどの一次資料で確かめ、条文や日付を添える。「危険」「有害」など、規制の中身より強い言葉は使わない。
- 運営者の感想（`reviews`）は、ユーザー本人が書いた内容だけ。前の商品の感想を後継品に載せるときは、その旨を必ず書く。
- **楽天ウェブサービスの規約**：取得した商品画像・商品情報をサイト側に保存しない（ページを開いた人のブラウザで `assets/rk.js` が都度読み込む）。楽天の情報を使う商品に、楽天以外のアフィリエイトを付けない。クレジット表示をフッターに出す。アプリIDは Cloudflare の環境変数 `RAKUTEN_APP_ID`、アフィリエイトIDは `src/build.js`。
- 中身の薄いページを作らない：成分ページは商品2件以上かつ辞書に説明がある成分だけ、ブランドページは商品3件以上。
