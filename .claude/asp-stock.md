# 広告リンクのストック（仲介サービスの提携済み・サイト未反映）

提携が済んで、まだ商品データ（`data/products.json` の `shop`）に入れていない広告リンクの置き場。
サイトに入れたら、その案件をこのファイルから消し、spec.md 10章の流れ（成分表の照合 → `shop` に登録）に乗せる。

**入れるときの決まり（spec.md 10章のおさらい）**
- 公式サイトに全成分がない商品は載せない。成分表は公式から2回取って照合する。
- 案件の説明にある宣伝文は使わない（下の「使わない言葉」）。クラベルの文は成分表から数えたことだけ。
- 価格は載せない。楽天の情報を使っている商品には付けない。
- 広告リンクは「テキスト」の種類（下のリンクはどれも「自由テキスト」＝テキスト用）。

### 反映するときの段取り（メモ）
1. `python3 tools/check.py find <商品名>` で登録済みか確かめる。
2. 公式サイトから全成分を2回取り、`tools/cands/` に貼って `python3 tools/check.py` で照合。
3. 商品画像は afb の素材を `assets/products/` に置く。
4. `shop` に `{"asp": "afb", "url": …, "pixel": …, "img": …}` を書く。ZACC は1つの案件でシャンプーとコンディショナーの両方が対象なので、2商品に同じリンクを付けてよいか、反映のときにユーザーと決める。
5. アフィリエイトリンクの追加は **B**（まとめて確認）。
